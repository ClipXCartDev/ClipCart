# Fonts

Drop a **`Roboto.ttf`** here — it's the default subtitle font used for FFmpeg export
(`ExportService`/`FontService.ensureDefaultFont`). Grab it from
https://fonts.google.com/specimen/Roboto (any regular-weight `.ttf`, renamed to `Roboto.ttf`).

Customers upload their own `.ttf/.otf` at runtime (per-subtitle) via the editor's
"Upload font" tool — those don't need to be bundled.
